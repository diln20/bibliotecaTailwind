# Tailwind Academy

Biblioteca educativa inspirada en la estructura progresiva de `bibliotecaDjango`, adaptada a **Tailwind CSS v4.3**.

## Incluye

- Ruta de aprendizaje por capítulos.
- Buscador.
- Progreso guardado en el navegador.
- Explicación sencilla, analogía cotidiana y “qué pasa por detrás”.
- Archivo exacto y explorador del proyecto en cada lección.
- Código copiable.
- Vista previa de cada concepto.
- Comprobación y actividad complementaria.
- Proyecto progresivo `tailwind_academy`.
- Proyecto final listo para Vite en `proyecto-final/`.

## Abrir la biblioteca

Abre `index.html` en el navegador. La interfaz usa el Play CDN de Tailwind únicamente para renderizar algunas vistas previas educativas.

## Ejecutar el proyecto final

```bash
cd proyecto-final
npm install
npm run dev
```

Para producción:

```bash
npm run build
npm run preview
```


## Enfoque pedagógico ampliado

La biblioteca explica las utilidades importantes **propiedad por propiedad**. Cada ficha incluye:

- propiedad CSS equivalente;
- familia de clases Tailwind;
- qué parte de la caja modifica;
- valores/clases frecuentes;
- cuándo conviene usarla;
- error común;
- ejemplo de código;
- vista previa visual.

También se añadieron lecciones separadas para `display/visibility`, `position/inset/z-index` y `overflow/aspect-ratio/object-fit`.
